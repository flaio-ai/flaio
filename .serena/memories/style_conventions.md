# Style & Conventions

- ESM modules with `.js` extensions in imports (compiled from .ts/.tsx)
- React functional components with Ink
- Zustand for state management (create pattern with getState())
- Zod for schema validation
- No default/fallback values for configuration - throw exceptions
- TypeScript strict mode
- kebab-case file names
- PascalCase for components, camelCase for functions/variables
